# Codex 原生深度主题系统设计

## 目标

将现有 12 套以背景图为主的皮肤升级为完整的 Codex 原生视觉主题，并新增 6 套原创主题。最终共 18 套，每套都能明显改变新任务首页、侧边栏、输入框、选择状态、按钮、边框、纹理与动效，同时保留 Codex 的真实功能和原生交互。

主题效果以“完整产品主题”而不是“壁纸覆盖”为验收口径。用户切换主题后，应能在三秒内仅凭界面结构、配色和装饰辨认主题，而不是只凭背景图辨认。

## 设计原则

1. **真实界面优先**：不注入不可点击的假功能面板，不用整张 UI 截图覆盖 Codex。
2. **首页表现力优先**：新任务首页允许大幅视觉重排，形成角色主视觉、主题标题和真实快捷入口卡片。
3. **对话可读性优先**：进入任务后降低装饰密度，背景保留主题氛围，正文区域保证稳定对比度。
4. **每套主题独立设计**：禁止仅替换图片和强调色。每套拥有独立的布局变体、组件造型、纹理、动效和主题签名。
5. **非 AI 模板感**：避免同构的居中角色、泛光渐变、随机装饰堆叠和错误文字。素材使用明确的插画媒介、受控色板、重复图形语言和人工排版规则。
6. **跨平台同源**：Mac 与 Windows 共用主题档案、CSS 与渲染配置，只在运行和安装层做平台适配。

## 主题范围

### 原有 12 套升级

1. 星核旅者：航天控制台、轨道弧线、黄铜与冷蓝指示灯。
2. 樱花信使：日系绘本、邮戳与信纸边框、粉紫花瓣动效。
3. 霓虹信使：雨夜街机、青粉霓虹、扫描线与路牌标签。
4. 雾海灯塔：版画海岸、灯塔光束、雾层与航海刻度。
5. 雨港余光：港口手绘、雨滴玻璃、暖灯反射和航运票据。
6. 绯红铸界：锻造工坊、铁牌组件、火星粒子和熔红描边。
7. 云鹿栖境：东方水彩、宣纸留白、云纹和印章式选中态。
8. 午夜终端：克制工业终端、细网格、状态灯和等宽标签。
9. 复古轨道：重做为真正的逐像素太空站主题，禁止平滑插画伪装像素风。
10. 策略中庭：建筑编辑部、纸张网格、黄铜尺线和模块化卡片。
11. 极光巨鲸：剪纸与丝网印刷感极光、鲸形轨迹和冷色玻璃卡片。
12. 墨岭守望：水墨木刻、山形分隔、金石印章和缓慢墨雾。

### 新增 6 套

#### 卡通主题

1. **邮差浣熊**：90 年代电视动画赛璐璐质感，海军蓝、邮政红和奶油白；卡片像邮件标签。
2. **夜班企鹅**：黑金舞台插画，聚光灯、唱片刻纹与节拍动效；输入框像录音台。
3. **工坊水獭**：手绘杂志拼贴，青绿、橙黄和蜡笔线条；快捷卡片像工作台便签。

#### 像素主题

4. **月台猫站长**：16-bit 夜间车站，靛蓝、琥珀灯和像素雨；侧边栏像站牌目录。
5. **软盘魔法师**：90 年代电脑桌面像素美术，紫蓝 CRT、软盘和窗口边框；选中态采用像素光标。
6. **深海维修队**：32-bit 潜艇控制室，深青、珊瑚橙和仪表灯；输入框像声呐控制台。

所有新增角色必须原创，不复制参考网站的动物造型、服装、名称、构图或标识。

## 界面架构

### 新任务首页

首页由换肤器识别原生首页容器后应用四层视觉结构：

1. **环境层**：高分辨率背景、纸张或像素纹理、主题色环境光。
2. **主视觉层**：角色或场景主体位于安全区域，不遮挡真实输入与导航。
3. **功能层**：将 Codex 原有建议项和可用操作改造成主题快捷卡片；没有对应原生操作时不制造假按钮。
4. **签名层**：主题名称、短标识和轻量装饰，不使用生成图片中的错误文字。

布局支持三种可配置变体：左文右画、上画下卡、仪表盘分栏。18 套主题至少覆盖两种布局，避免同一模板批量换色。

### 任务对话页

- 背景图显著但不压过正文，主内容区使用按主题调色的半透明阅读层。
- 侧边栏保留主题纹理、边缘光和选中态，不再退化为纯黑色块。
- 输入框拥有主题边框、焦点光、按钮形状和简短主题签名。
- 正文文本、代码块、弹窗与系统提示维持原生语义和无障碍对比度。
- 动画只作用于装饰层，不移动正文、不干扰滚动、不持续占用高 CPU。

## 主题档案

在现有 `visual` 配置上扩展为数据驱动的主题档案：

- `layoutVariant`：首页布局变体。
- `surfaceStyle`：玻璃、纸张、金属、像素或墨染表面。
- `cornerStyle`：圆角、切角、像素角、票据齿孔等。
- `texture`：可选的低透明纹理资源。
- `motionPreset`：花瓣、雨滴、扫描线、火星、星轨、墨雾或关闭。
- `sidebarStyle`：侧边栏透明度、分隔线、项目选中态与图标处理。
- `composerStyle`：输入框形状、强调色、主题签名和焦点效果。
- `homeArt`：主视觉资源、焦点、安全区及遮罩强度。

旧主题档案缺少扩展字段时使用稳定默认值，保证升级不破坏已保存主题。

## 素材标准

- 背景与首页主视觉母版均为 3840×2400 或等效 4K 横向尺寸。
- 卡通插画要求明确媒介：赛璐璐、绘本、水彩、杂志拼贴或丝网印刷，不使用泛化 3D 可爱角色。
- 像素主题必须使用固定像素网格、有限色板、硬边缩放和一致像素密度；禁止先生成平滑插画再套马赛克滤镜。
- 图片中不生成界面文字。所有标题、标签和数字由 HTML/CSS 渲染，避免乱码和低质 AI 排版。
- 每套主题保存色板、线条、纹理和角色轮廓约束，后续迭代保持一致。

## 动效与性能

- 默认动效包括 1 个环境动效和不超过 2 个交互动效。
- 环境动画目标 30fps 以下、只使用 `transform` 与 `opacity`；焦点和悬停动画目标 60fps。
- 遵循 `prefers-reduced-motion`，启用后关闭循环动画并保留静态主题效果。
- 不创建无限增长的 DOM，不使用 Canvas 持续重绘，不拦截鼠标和键盘事件。
- 主题切换和恢复官方外观继续使用现有安全热应用流程，不新增 Codex 自动重启。

## 兼容与失败处理

- DOM 标记识别分为首页、任务页和通用降级三级；新版 Codex 结构变化时优先降级到背景、侧边栏和输入框主题，不隐藏原生内容。
- 任何关键资源缺失时拒绝报告成功，保留上一套完整主题。
- CSS 注入继续通过安全选择器与属性白名单校验。
- Mac 与 Windows 都必须验证 18 套主题档案、资源完整性和运行时同步。

## 验收标准

1. 18 套主题均可一键应用和恢复，Mac 与 Windows 配置一致。
2. 原有 12 套不再只有背景变化；首页、侧边栏和输入框至少有三处主题独有差异。
3. 新增 3 套卡通主题没有泛化 3D AI 感，新增 3 套像素主题通过像素网格检查。
4. 首页所有可点击视觉组件均映射真实 Codex 操作。
5. 对话页正文、代码块和输入区达到可读对比度，不出现背景遮字。
6. 关闭动画偏好生效，长时间使用无持续高占用。
7. 皮肤页面继续只对管理员显示，普通用户不可进入测试入口。

## 实施顺序

先制作“邮差浣熊”和“月台猫站长”两套标杆主题，验证完整首页、任务页、动效和跨平台配置；标杆通过后再按同一组件系统升级其余 16 套。这个顺序只影响开发批次，不减少最终 18 套交付范围。
